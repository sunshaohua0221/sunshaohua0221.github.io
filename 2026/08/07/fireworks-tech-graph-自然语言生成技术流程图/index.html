用自然语言生成技术流程图的 Agent Skill：fireworks-tech-graph

写技术方案、做架构评审、给同事讲一个系统怎么跑——这些场景里最耗时的往往不是思考，而是「把图做出来」。要么打开 draw.io 一个个拖框，要么手写 Mermaid DSL 反复调试缩进，改一个箭头全图错位。最近试了一个 Agent Skill：**yizhiyanhua-ai/fireworks-tech-graph**，思路很直接——用中英文描述系统，它直接吐出带几何校验的 SVG、高清 PNG、语义动图 GIF，以及可离线交互的 HTML。本文记录它的能力边界、怎么装、怎么用，以及和 Mermaid / draw.io 到底差在哪。

它的口号很直白：”Stop drawing diagrams by hand.”（别再手绘图表了）。实测下来，对 AI/Agent 这类新兴系统的可视化尤其顺手。

1. 为什么需要它

先说痛点。我们常用的两件套各有硬伤：

Mermaid draw.io fireworks-tech-graph
自然语言输入 ✗ ✗ ✅
AI/Agent 领域模式 ✗ ✗ ✅
多种视觉风格 ✗ 手动 ✅ 内置 12 种
高清 PNG 导出 ✗ 手动 ✅ 自动 1920px
语义箭头颜色 ✗ 手动 ✅ 自动
不依赖在线工具 ✅ ✗ ✅

Mermaid 适合在 markdown 里快速画个草图，draw.io 适合手工精修，而 fireworks-tech-graph 优化的是「描述一个系统、立刻拿到成图」 这条路径——不用写 DSL 语法，也不用在点阵 GUI 里拖来拖去。

它本质上是一个 Agent Skill，同一份代码无需改动即可跑在 Codex 和 Claude Code 里。当你在对话里说「画个图」，它会把你的自然语言转成一份版本化的 Diagram IR（JSON 中间表示），再经风格系统渲染成图。

4. 输出格式与能力边界

它输出的不是 Mermaid / PlantUML 文本，而是直接渲染好的图：

  • SVG：用于二次编辑，纯 inline SVG，不请求外部字体。
  • PNG：自动 1920px 高清，便于直接贴进文档/PPT。
  • GIF：聚焦语义动效，唯一支持的动图格式，默认 960px、5.75s、20fps、共 115 帧。输入一个语义 SVG，产出一段紧凑、经过 probe 的 GIF。
  • 离线交互 HTML：单文件导出，带平移/缩放、主题切换、复制，以及 SVG/PNG/JPEG/WebP（最高 4×）下载。

关键边界：它不产出 Mermaid 或 PlantUML 文本。如果你要的是可版本化、可手改的 DSL 源码，那它不合适；它要的是「描述即成品图」。两者是不同定位，不是替代关系。

图表类型覆盖面很广：基础 7 类（Architecture / Data Flow / Flowchart / Agent Architecture / Memory Architecture / Sequence / Comparison / Mind Map）、完整 14 种 UML（类图、组件图、部署图、时序图、状态机图、活动图、ER 图……），以及一整套 AI/Agent 领域模式。

5. 内置风格与领域模式

风格系统是这个 skill 的精华——样式指南被编码进了生成器，而不只是文档描述。共 12 种视觉风格：11 个生成器支持 + 1 个 AI 编写的「Dark Luxury」。其中 4 个工程风格还带了可执行契约，专门服务 C4 评审、云部署、事件流、可靠性排查这类场景。

内置的 AI/Agent 领域模式可直接调用，不用自己描述布局：

语义形状也有约定：LLM 用双边框圆角矩形，Agent 用六边形；颜色 + 虚线编码「读/写、异步、循环」等含义。这让图「一眼能读懂」，而不是一堆无差别的方框箭头。

6. 统一 CLI 与几何校验

除了在对话里用，它还提供统一 CLI fireworks.py，可校验、渲染、检查、导出、动图：

它有一套叫 Loop Engineering（循环工程） 的机制保证出图质量：首帧只是候选，通过「合同 → IR → 风格 → 路由 → SVG → 校验 → 视觉回读 → 修订」的反馈闭环，最多两轮修正，最终产物会明确给出：

渲染器三选一，按质量和安装成本取舍：

Renderer 质量 安装成本 适用
cairosvg 好 一条 pip install 默认，最均衡
rsvg-convert 一般 系统包 无 Python、扁平简图
puppeteer 最好 Node + Chromium 需像素级/浏览器渲染

几何上它强制零交叉、每条边最多 2 个弯、节点间距 ≥40px、容器留白 ≥20px、标签不压节点和连线——所以成图基本不会出现「箭头穿过框」的尴尬。

7. 小结与适用场景

  1. 它是「描述即出图」的成品工具，不是 DSL 编辑器。要可手改的 Mermaid 源码就别用它。
  2. 对 AI/Agent 系统最香：RAG、Multi-Agent、Memory、Tool Call 等模式开箱即用，不用自己想布局。
  3. 装一次、双运行时通用：Codex 和 Claude Code 共用同一份 skill，git clone 还能符号链接共享。
  4. CLI 适合进流程：validate/render/check/animate 可以接到 CI 或自动化脚本里，配合 validation: passed 门禁做质量卡点。
  5. 几何校验是真省心：过去手画或写 Mermaid 最常翻车的「线穿框、字压线」，被构图契约从源头防住了。

如果你也受够了为一张架构图在 draw.io 里拖半小时，或者 Mermaid 缩进调到头秃，值得试试这个 skill——一句话描述，剩下的交给它。
